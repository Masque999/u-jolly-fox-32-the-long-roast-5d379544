# The Long Roast

One line, at most 200 characters, roasting my own AI agent.

Entry: `My agent read 40,000 tokens of instructions, nodded wisely, and then asked me what the task was. Twice.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
